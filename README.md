# quick-notes-frontend

 **dashboard application** built with **next.js**. .


## Tech Stack

- **Frontend:** Next.js(app router), TypeScript
- **design framework**:MUI 


## Installation

1. Clone the repository:

## HTTP
git clone https://github.com/lajvanti-sonaiya/dashboard-design.git

## SSH

git clone git@github.com:lajvanti-sonaiya/dashboard-design.git

cd dashboard-design

2. Install dependencies
npm install


3. start server

npm start or npm run dev
